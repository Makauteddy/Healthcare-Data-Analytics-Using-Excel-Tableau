# Healthcare-Data-Analytics-Using-Excel-Tableau
## Project Overview

This project analyzes a synthetic healthcare dataset containing 55,500 patient records to uncover insights into patient demographics, medical conditions, hospital admissions, length of stay, billing, insurance providers, medication usage, and clinical test results. Microsoft Excel was used for data cleaning, preparation, and exploratory analysis, while Tableau was used to create an interactive dashboard that presents key healthcare KPIs and trends in a clear and accessible format. The analysis highlights important findings, including high emergency admissions, a large 60+ patient population, longer hospital stays for Alzheimer’s and Cancer patients, and a high proportion of abnormal test results, providing insights that can support better resource allocation and healthcare decision-making.
